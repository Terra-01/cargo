# Shader file licenses

Shader source files in `src/lib/shaders/` are ports of work from other open-source projects. Each ported file retains its origin's license and attribution.

| File | Original | Author | Source | License |
|---|---|---|---|---|
| `neat-gradient.ts` | Neat | FireCMS | https://github.com/FireCMSco/neat | MIT + Commons Clause |
| `rainbow-warp.ts` | "Rainbow" | Shadertoy contributor | https://www.shadertoy.com/view/Ws3SRn | CC BY-NC-SA 3.0 |
| `ether.ts` | "Ether" | nimitz | https://www.shadertoy.com/view/MsjSW3 | CC BY-NC-SA 3.0 |

### Notes on the Neat license

Neat is licensed under MIT plus the Commons Clause. MIT permits use, modification, and
distribution. The Commons Clause forbids selling a product whose value derives substantially
from the software. Cargo is a free, non-commercial project, so this is satisfied. The Neat
attribution and license notice are preserved here and in the code-export header (Phase 11D-4).

### Notes on the Shadertoy ports

"Rainbow" and "Ether" are CC BY-NC-SA 3.0: attribution preserved, non-commercial use,
share-alike for derivatives.

The rest of the Cargo project remains under its general "free, forever" terms.
